# CSCI-434-COLL-400-Final-Project-

Monitoring and Analyzing computer network traffic, particularly from popular internet websites such as Google, Facebook, and YouTube.
Extracting features from website traffic data and build models to classify the specific website from which the traffic originated.
The classification is done automatically, without access to the website URL or data payload that is typically encrypted.
